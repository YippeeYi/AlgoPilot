# M3.2.1 人工教学质量评审

本表待真实人工填写。自动程序只检查难度范围、公开 Tags 关联、重复、排序因素和依据引用，不能代替教学质量评价。

[逐题评审 CSV](m321/manual-review.csv) 共 40 行，来自 8 类合成选手的推荐。题目元数据来自 2026-10-12 官方 CF API 录制；选手历史、偏好和计划标记是合成输入，不是实际用户能力数据。CSV 的评审者/时间/结论/建议字段全部留空，没有假装完成评审。

## 每题流程

1. 阅读对应场景输入（`tests/evaluation/scenarios.ts`）和推荐理由/依据（[固定结果](m321/recorded-catalog-scenarios.json)）。输入的 Rating 是题目难度，自评不是官方选手 Rating。
2. 在 CSV 的官方 URL 打开完整题面，结合约束、实现负担、证明难度和先修知识独立判断。Tags 只供评审比对，不足以断言教学适合。
3. 在 `assessment` 填一个值：**适合、偏简单、偏困难、方向不符、理由缺乏证据**。若多个问题并存，选主要问题，其余写入建议。
4. 填 `suggestion`、`reviewer`、`reviewed_at` 和 `statement_consulted`（已读/未读）。未读完整题面不得当作正式“适合”评价。
5. 多名评审者可各复制一份 CSV，记录分歧，不用 AI 多数投票充当人工结论。

## 标准

| 判断 | 需要考虑的证据 |
| --- | --- |
| 适合 | 难度/先修知识/训练目标合理，用户能独立尝试；理由与记录一致 |
| 偏简单 | 对该场景缺少有效挑战，须说明为何题目 Rating/约束不能反映真实训练价值 |
| 偏困难 | 先修知识、实现或证明门槛超出场景，须说明缺少什么准备 |
| 方向不符 | 标签匹配但核心学习任务不服务目标，或训练目标和推荐内容有偏离 |
| 理由缺乏证据 | 推荐声称的提示依赖、复盘结论或近期覆盖无法从对应输入/记录支持 |

“方向标签数量”不是教学多样性。每类选手的 5 题应另评是否相互重复、是否有合理的练习顺序、是否需要一题验证后再推进。图论/DP 定向场景出现 5/5 同方向可能符合集中训练，但也可能过度集中，不能仅凭命中率决定。

优先人工检查进阶场景的 `130/I`（*special）和 `2129/C3`（interactive）；元数据不会自动证明它们适合当前目标。本轮没有根据未读题面擅自判错或自动删除题目。
