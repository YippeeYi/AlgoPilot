# M3.4 推荐质量评审与小规模真实选手试验

本阶段保持 deterministic/1.3-official 的所有权重、主逻辑和线上标注。真人原队列 **0/40**，替代题 **0/5**，真实参与者 **0**；以下为可执行方案，不是已取得的教学收益。

## 评审包

[五题评审材料](m34/five-problem-review.md) 包含完整题面入口、官方题解/发布解法入口、核心任务、先修建议、当前难度与原推荐理由的证据边界；面向评审者，包含解法线索，不能提前给独立训练选手。1658D2/1895E 为高级探索候选，1106D 为图方向，1253C/2069C 为 DP 方向；泛 Tags 不等同核心算法。1253C 官方展开正文未取得，独立推导明确标为 AI，不伪称官方证实。

原 40 条 AI 初评 33/2/5 不改，原始人工表保留，五题仍在当前 40 题队列中；是待审子集，不额外冒充 45 个不同推荐。按 scenario + problem_key 人工覆写并保留修改历史的操作见评审包。AI 自核验没有增加真人数量，也不进入线上画像。

获准公开 CF 响应的隔离闭环另显示：开启官方证据排除 18 道默认难度区间内已观察 AC，撤销后候选恢复、官方引用清零。使用的是合成 AlgoPilot 冷启动偏好，不能作为该 Handle 本人的推荐满意度。真人评价及训练观察仍为空；独立的静态大历史游标模型发现 1 万条可能需要 64 轮手动继续，需在获准测试环境实测体验后再决定修改。

## 试验预登记：可比性优先

先招募建议 4–8 名知情选手，按自选训练区间/目标描述，不以人数假设统计功效。由研究负责人邀请，本轮未发送邀请。参与者可以退出，无需交出 CF 密码、Cookie、代码。分别记录：使用历史作推荐的同意、记录评估结果的同意、是否允许发送题面/代码给配置 Provider、是否允许分享去标识结果；后三者不能由公开 Handle 或一般参与同意代替。

A 为 AlgoPilot 当前个性化排序；B 为普通 Rating 距离＋可选 Tags 筛选，等距用预登记种子散列打破平局。**两组使用同一当前授权证据版本、同一候选快照、同一难度范围/参考难度、主题、题数、特殊题型限制、全历史已知完成与计划约束。** B 使用 A 已计算的参考难度是保守控制，主要比较排序/匹配价值，不宣称比较了整个冷启动和难度建模系统。

候选来自已核验部署的 learning_candidates，不能拿 CF 全库无已做/交互过滤结果作弱基线。若人为排除计划内题，必须在 A/B 共同候选生成之前同时排除，并让 A 在该共同池重算；不能只让 B 训练已计划题。当前 600 池与扩大池的敏感性分析独立报告，不与 A/B 教学收益混算。

每个参与者两个训练 block，每个 block 在开始前同时冻结 A/B 列表、证据 revision 和元数据。采用预登记种子的成对 AB/BA 分配，第二 block 顺序反转；奇数参与者单列说明不完全平衡，不能后验按成绩调顺序。可用不同主题 block 或记录先前接触以缓解学习迁移，不能声称消除了迁移。下一 block 才更新训练/复盘画像，两组一起刷新；不能 A 用更新历史、B 用旧快照。

第一步只看去标识列表 X/Y，每组最多五题、展示信息相同，先评分适合程度；先不显示个性化理由，避免仅措辞造成偏好。然后分别展示理由评“可信/可追溯”，不要把理由喜好当作学习收益。若两组推荐同题，保留共同推荐比例；同题的训练结果不能计两次独立 A/B 成果。

每个 block 从两组按原排序选择一对未做、未见过的不同题，Rating 相差不超过预登记的 100，主题一致；由不知道参与者成绩的协调者按固定规则配对。若无法满足，记录不可比较/共同推荐，不降低 B 条件、不为 A 挑容易题、不用反复换题挑结果。列表适合度评审仍可进行。先修缺失/未知 special 由协调者事前同规则检查，发现不适合需同时撤下对应比较并记录原因。

同一选手两组同训练时限（如 45 分钟，进阶可预登记 60 分钟），同一 Tutor 权限和提示请求规则，不自动放宽 L0–L5、L5 双确认或竞赛限制。不强迫使用提示；记录实际最高已看等级、外部题解和未查看提示，不把无提示直接当独立。中止/未完成单列，不拿缺失当失败或零提示。可观察到的官方 OK、用户自报及代码一致性仍分列。

AC 后两组同样复盘机会，发送 Provider 必须单独同意；不愿发送代码可人工回顾而标明来源不同。记录复盘中新暴露问题及其来源，不因 AI 一次指出就断言薄弱。题目分析影响下一 block 的共同证据快照，不能只更新 A 训练状态。

## 准备脚本与数据边界

[m34-study.ts](../scripts/m34-study.ts) 只离线生成等题数 A/B 列表与顺序，无网络/模型/数据库写入，不接收私人源码。输入要求 participantId=P001 等去标识 ID、consentId、consented=true、明确 RPC 快照来源、证据版本、共同池和 A 的排序 ID。此声明不能证明真实同意/快照可信，研究负责人须核验原同意记录与授权 RPC 的导出过程；本轮只用 SYNTHETIC 夹具。

```bash
node scripts/m34-study.ts /private/study/approved-input.json /private/study/prepared-block.json
```

输出使用 wx，不覆盖既有 block。种子、原始同意及 ID 对照表保存在私有目录；不将私人证据/JWT/代码写入仓库或自动发送模型。完整输入字段见脚本 input schema；eligiblePool 每题仅 id/contestId/index/rating/tags，personalizedIds 为相同池的 A 列表；需要完整全历史过滤来源，不以 500 条画像代替已做全集。基线和 A 的方向/理由如可能剧透，应在目标和披露同意内展示。

[准备输入空模板](m34/study-input.template.json) 的 consented=false，缺字段会被脚本拒绝；负责人在私有副本中补齐真实同意和快照。[训练观察空模板](m34/study-observation.template.json) 使用 NULL 表示未观察，不能将模板行计作参与者或完成记录。review_type=human 只是填写入口，空内容不算真人评价。

## 记录模板与修改历史

可复制下表或使用私有 JSONL。没有参与者时只保留空模板，不生成虚假观察行。

| 字段 | 定义/允许缺失 |
| --- | --- |
| event_id / supersedes_event_id / reviewer / recorded_at | 追加事件 UUID、被覆写事件 ID、真实记录者、UTC；旧事件只读，撤销单列事件 |
| participant_id / consent_id / consent_version | 去标识 ID、私有同意索引；同意撤销后停止采集/分析，按约定删除或匿名化 |
| block / order / masked_arm / actual_arm | 预登记顺序；actual_arm 对选手和初评教师盲化，解盲时间单列 |
| engine_version / pool_hash / metadata_time / evidence_revision / official_revision | 可复现输入；记录偏离协议，不伪造缺失哈希 |
| scenario / problem_key / pair_id / previously_seen | 题目与场景键；见过/已做不在新题训练比较中混用 |
| suitability / difficulty / goal_match | 适合、偏简单、偏困难、方向不符、理由缺乏证据；不确定留 NULL |
| reason_supported / evidence_refs / missing_prerequisite | 理由依据能否核对、引用、先修；教师意见不覆盖选手意见 |
| outcome_self_report / official_verdict / source_match | 自报/官方分开；source_match 保持未验证 |
| highest_hint_seen / external_help / stopped / duration_minutes | 系统观测与自报分别注明，缺失 NULL；时间不作为独立能力证明 |
| review_source / new_issue / issue_confidence | 人工/AI/无复盘、问题、样本和可信度；无发送授权不记录私人代码 |
| withdrawal / protocol_deviation / suggestion | 退出与原因可选，不强迫解释；组间差异完整记录 |

人工结果修正追加新事件并引用 supersedes_event_id；原值与新值均保留，汇总按每个 participant/block/problem 的最新有效事件，不能把修改次数当多位选手。撤销后的汇总重算并删除不再获准保留的个人记录；公开只发布获单独同意的去标识聚合。

## 分析与发布门槛

先报告人数、实际可比题对、共同推荐、退出/缺失和不同顺序/区间。以**选手为配对单位**汇总 A−B 的适合度、目标匹配、高等级提示比例及“过简单/困难”等计数；列中位数/范围和分母，题目行不能冒充独立样本。复盘问题和理由真实性列质性例子，仅用获准去标识内容。人数少只报告观察，不做显著性或因果收益宣称，不后验挑指标。

目前无真人结果，无适合率或学习收益估计。只有专用环境真实 JWT/授权隔离通过、具备故障恢复与告知流程，且参与者同意后才进入真实训练；当前仅具备评审材料与离线试验准备条件。
