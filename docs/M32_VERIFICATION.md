## 新增自动化覆盖

- 冷启动不强制 Handle，默认区间明确暂定，最多 5 道真实缓存题，不伪造能力或历史；难度自评、范围/主题/目标可保存并刷新恢复。
- 历史提示与难度影响排序/参考难度，理由引用训练 ID；实际授权升级不增加 maxHint，HMAC settle 实际披露才影响画像。
- 画像按不同题最新完成训练去重，5 题以下样本不足，无提示不证明独立；不同难度区间、自报结果、提示分布与思路记录数量分别展示。
- 快照保存不算 AI 分析；审核并 HMAC 保存完成复盘后，授权提取知识/风险对推荐与画像产生可追溯影响；关闭授权后停止使用，分析原记录保留。否定风险语句不会生成重复风险建议。
- 完整数据库历史排除已知自报解出/AC 复盘题；实际 SQL 用 501 条较新夹具使一条已解记录退出 500 条画像窗口，仍正确排除，主动重练可恢复候选。
- 活跃计划内降权，同题可跨计划、同计划去重、原 revision/CAS/requestId 保留；手动完成不当 AC，删计划保留训练/复盘。原跨页多选、重排与新一轮训练回归通过。
- 反馈持久化、幂等/不同指纹 PT409、难度范围内调整和题目降权，刷新后的下一轮继续生效；反馈不写解题/官方状态。
- 新私人表 RLS、两个用户各自偏好/训练/反馈/复盘/画像隔离，匿名拒绝，禁止直接 DML/伪造官方证据和字段越权，SECURITY DEFINER/ACL 检查通过。
- Rating NULL 不推荐；无主题时缺 Tags 可按难度推荐，有主题则排除；无匹配安全空状态；缓存错误不造题、可读错误与重试，学习偏好/画像不依赖 CF 请求成功。
- 默认推荐不返回 Tags 或命中算法名；结束但未解且未看 L5 的训练方向不展开。缺题面 Tutor 在模型入场前拒绝，用户保存补充上下文后进入既有 Tutor；L0–L5、L5 两操作、contest/completed、签名/租约/额度等旧回归保留。
