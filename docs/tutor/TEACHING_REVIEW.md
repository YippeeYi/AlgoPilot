# M2 教学人工审核

`teaching-review-dataset.json` 是本项目原创的 12 道训练题，覆盖贪心、DP、二分、图论、数论、位运算。不是 Codeforces 官方题目导入，也不作为产品假题库或假统计。固定 approved/rejected 输出仅检验审核器，`realModelReviewed: false` 表示尚未调用真实模型人工验收。

在隔离测试账户中录入题面和已有思路，依次测试 L0–L5、validate/counterexample/complexity/debug（自行补充静态 C++ 草稿）。每个等级先授权，随后主动请求；L5 必须走两次确认。记录 Provider/model、Prompt 版本、消息 requestId、实际 usage、日期、审核人及输出，不记录 API Key 或内部推理。

每项按 0（不合格）/1（需改进）/2（合格）评分：

| 维度         | 通过标准                                                                               |
| ------------ | -------------------------------------------------------------------------------------- |
| 提示边界     | 低等级没有新算法、关键观察、伪代码或完整答案；引用用户已经写出的内容与主动新披露要区分 |
| 正确性与证据 | 不无依据判错；成立的推导明确确认；猜想和证明分开                                       |
| 反例可信度   | 候选输入标为未执行验证；人工检查输入合法性和是否真的反驳主张；本应用不执行用户代码     |
| 连续性       | 回应当前思路、版本和已回答问题；不重复同一个无价值问题                                 |
| 针对性       | 一次一个主要问题，针对当前最关键的缺口，避免空泛鼓励                                   |

另外检查缺失约束时复杂度是否说明不确定、代码分析是否定位到实际行段、Markdown/公式是否可读、完整修复代码是否仅 L5。L0/L1 使用受限的结构化选择和服务端模板，表达自由度较低，应专门评估引用是否有用、提问是否准确。

发布真实 AI 功能前，所有低等级泄露或虚假验证案例必须修复并复测；不能用固定夹具的自动化分数宣称真实教学质量通过。自动规则与模型自报等级无法形式化保证 L2 以上不剧透。保留不通过的原始可见消息作为回归案例；敏感内容不要进入公共数据集。
