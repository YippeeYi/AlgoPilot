- `src/server/codeforces/account-parser.ts` / `account-upstream.ts`：固定官方公开 API、当前 Handle 校验、下降 ID/成员校验、最小字段、无源码、响应/超时边界。
- `account-service.ts` / `account-repository.ts`：事务外请求、全局时隙、身份哨兵、有限 head/history/pending 批次、独立持久化和相同批次 ID 的未知确认重试。
- `src/features/learning/cf-cursor.ts`：SQL/TypeScript 对照的重叠、EOF、漂移、高水位规则；预算不等于完整。
- `supabase/migrations/202610150010_cf_official_evidence.sql`：私有 RLS 证据/账号/回执，HMAC/普通 JWT RPC、scope/租约/CAS、原学习 RPC 扩展及证据 guard，追加修正 cf_sync 锁后时钟。

- `src/components/learning/cf-account.tsx`、`ability-profile.tsx`、`evidence-links.tsx`：来源/覆盖/可信度、失败刷新状态和原请求重试、各来源代表引用。

训练、计划和 Review 记录不会被公开 OK 回写。导入代码仍自报、source match 未验证，官方提交不解锁 Tutor 等级、不升级 maxSeenLevel、不绕过 HMAC/额度/租约。未 AC 缺题面逻辑和旧历史兼容继续回归。

## 官方事实与分析边界

官方证据仅为“关联公开账号有此题 OK 提交”，按 contestId/index 去重，引用采集行 UUID、提交 ID、Handle/采集时间与官方链接。系统实际提示、自报结果/外部帮助与 AI 复盘独立保留；不把官方 OK 说成本人独立完成，不验证本地源码，不按 WA 数量、耗时或没有提交推断能力不足。

画像最近 500 道官方 OK 与最近 500 次训练去重合并题目样本，分别展示两个来源计数；不足五题为样本不足，更多也只有“有限证据，公开账号归属/独立性未知”。元数据无法匹配则 Rating NULL/Tags 空，不产生知识或难度结论。大量低难度 AC 不提升参考难度、不稀释高等级提示弱项；AI 贡献仍最多 6，不累加。

推荐全历史已观察 OK 在 600 候选前排除，主动重练例外。近期所选难度最多 20 道官方覆盖补充原新颖度/探索因素；说明来自实际覆盖和评分，不给官方能力评级。关闭授权或删除立即递增证据 revision，新画像/推荐重算并拒绝在途旧快照；private,no-store，没有持久派生画像缓存。已打开页面展示的是先前快照，需刷新取得新事实。

## 隔离数据库与安全

[M33 原生 PostgreSQL 结果](m33/isolated-postgres.json)：PostgreSQL 18.4，**三个独立 backend、9 检查组**；临时 loopback 集群结束后停止/清理。Auth uid/claims 为测试替身，不是签名 JWT/PostgREST。

复现旧 006 cf_sync 在锁前读取时钟，另连接持锁 3.2 秒后两次请求可连续放行；010 追加替换后，同样锁等待结束仍保留 >2.5 秒时隙。账号/题库、不同用户/实例使用一个 global next_slot_at，不提供第二套额度。网络请求不在数据库事务中。

三连接验证同用户租约竞争、相同批次并发只保存一次、相同公开 Handle 的两用户私有采集独立、跨连接关闭授权使旧 guard 返回 PT409、旧 worker 无法继续；直接读写私人表与伪造跨用户签名均 42501。010 重跑原子拒绝，函数定义不变；001–005 创建的实际历史 custom/session 经 006–010 不改变。cf_account_state/command/guard/cf_sync 均空 search_path、SECURITY DEFINER、无 anon EXECUTE。

[保留的旧原生回归](m33/legacy/isolated-postgres.json)：001–009、三个 backend、原 12 检查组通过；修正旧运行器的报告，使 migrations 只列实际应用的 001–009，不错误列入 010。真实 11,450 题和 500 次训练，旧 RPC 十次采样证据中位 3.04 ms/P95 3.56 ms，候选 15.38/16.53 ms；这是旧版本隔离对照，不能冒充新增 SQL 的线上延迟。

PGlite 新用例另验证：多页逐批保存、租约过期恢复、页中新增引起的重叠漂移、失锚重启、短页不完整/空 EOF 才记录扫描上界、高水位增量、NULL/TESTING→OK/OK→WRONG_ANSWER/CHALLENGED、同题多 AC、重复 ID/请求、题号身份冲突、旧作用域拒绝、更换/解除/删除、双用户读取/ACL、真实录制回放。整个历史确认空后撤下旧活跃提交、清除派生 AC，不伪造“未解”训练。HTTP 429/API FAILED、网络/TimeoutError 模拟与上游预算验证有界尝试、每次共用时隙、已有成功批次保留。原权限、Review、Auth、CAS、安全输出和历史断言保留。
