## 数据接口

所有接口验证服务端 getUser；私人响应 `private, no-store`，POST 同源、JSON、有界正文、严格 Zod 白名单。数据库 RPC 独立核对 auth.uid、字段与约束，SECURITY DEFINER `search_path=''`，仅 authenticated EXECUTE；新表启用 RLS，用户无直接 DML 权限。

| HTTP | 用途 |
| --- | --- |
| GET `/api/v1/learning` | 同一证据模型生成画像、当前偏好和 revision；不返回代码、模型原文、nonce/usage/内部证据 |
| POST `/api/v1/recommendations` | `{exclude?: UUID[]}` 最多 5 个上一轮题目；读取已有可信缓存，复用旧 TTL/限流/失败回退，再从 SQL 候选生成推荐 |
| POST `/api/v1/learning/preferences` | `{requestId,revision,preferences:{min,max,themes,goal,repeat,reviewEvidence}}`；难度 800–3500、min≤max、最多 5 个白名单主题；goal balanced/independence/explore |
| POST `/api/v1/learning/feedback` | `{requestId,problemId,kind}`；kind too_easy/too_hard/off_goal，偏好反馈不表示 AC 或能力结论 |

写入 `learning_write` RPC 使用用户锁、偏好行锁、CAS 与私有 requestId 收据。相同请求重放幂等；不同指纹或旧 revision 返回 PT409。反馈每题取最新一条，最多 100 题；重复点击/传输重试保持 requestId。计划关联仍调用原 plan_write，跨页多选与多计划唯一约束不变。新训练仍调用原 start_cf_session，Tutor/Review HMAC 与额度/租约不改。

## 来源与安全边界

- CF Rating/Tags 是官方题目元数据；不等于选手官方 Rating，不是完整题面。
- outcome=solved_self_reported 是用户自报；AC 复盘进入时的显式自报也来自既有授权事件。官方提交目前未同步，本地源码一致性仍 unverified。
- 提示采用 max_hint_seen，实际披露而非 allowedLevel。外部帮助可能未知；没有提示不证明独立完成。
- 思路版本只计非空保存记录，不读取用户思路文本推断质量。
- 复盘证据需新偏好 reviewEvidence=true 的额外主动授权，仅已授权快照的 completed 结构化分析参与。每题取最新分析，最多 200 题；pending/failed/快照/编辑笔记都不算生成证据。仅词汇/风险类别映射，保留 analysisId/reviewId，不发送新 Provider 请求，标记 AI 推测/未验证。
- 关闭授权后停止使用复盘证据，原有快照/生成历史不删改。新增学习证据不会写回 AC 前 Tutor 历史或 maxSeenLevel。
- 未解题推荐不输出 Tags/匹配算法名；主动选择主题前告知方向提示。已结束但未自报解出且未看 L5 的训练不展开知识方向，仍统计难度/实际提示。
- Tutor 从 snapshot 或用户主动保存的题面上下文获得题面；完全缺少时 422 STATEMENT_REQUIRED，不入场、不耗额度/调用模型。题面是否完整仍需教练根据用户信息确认，禁止按标题/Tags 猜题。

## 确定性 V1

共享模型与权重：`src/features/learning/engine.ts`；数据读取：`src/server/learning/repository.ts`；数据库过滤：007 `learning_candidates`。

1. SQL 基于当前可信 catalog_version，遵守难度范围和任一明确主题。排除 NULL Rating；有主题且 Tags 缺失则排除。默认从完整历史（不受画像窗口影响）排除自报解出/已有 AC 复盘题，允许主动重练。活跃计划内同题标记为降权，手动计划完成不能当 AC。
2. 按官方 Tags 首项分层，在每层按难度距离/稳定题号选择；全池最多 600。用户浏览器不下载全题库，不逐字请求 CF。
3. 参考难度：少于 3 道不同自报解出题采用区间中点；至少 3 道采用题目 Rating 中位数，半数以上实际 L3+ 时下调 100。此处只是有限证据下的排序参数。难度反馈每题最新、最近 20 条相关难度反馈，太简单 +100、太难 -100，总调整最多 ±200；始终裁剪到用户范围。
4. 每轮确定性贪心选最多 5 道，后选题重算当轮覆盖。分数为排序单位，不是能力分。

| 因素 | 权重/行为 |
| --- | --- |
| 难度适配 | 40 × 难度距离适配度 |
| 待加强方向 | 22 × 有关已完成题目高提示/未解信号比例；少样本分母至少 3，最多 1 |
| 明确目标 | 16：均衡考虑主题；独立目标加强待验证薄弱方向；探索加强近期未覆盖方向 |
| 新颖/重复 | 新方向 +10；近 20 次训练中同题 -10 |
| 当轮多样性 | 未覆盖方向 +12 |
| 活跃计划 | -24，仍允许跨计划关联 |
| 用户反馈 | 曾反馈此题不合适 -60；不强行改变结果事实 |
| AI 复盘建议 | 6，低于真实训练/明确目标；只是相关知识的待验证信号 |

平分按稳定 UUID 排序。重新推荐临时避开上一轮最多 5 题；替代不足时降权复用并明确说明。每题解释输入范围、历史/提示/复盘或反馈证据、计划/重复因素；可打开原训练/复盘依据。偏好/官方难度等无需私有历史也能解释，不能生成虚构理由。

## 画像及局限

最近 500 次训练、每题只取最近完成记录。同一题多次训练不增加方向样本。知识方向及 400 分题目难度区间展示真实样本、自报解出和实际高等级提示；少于 5 道不同题目标“样本不足”，更多也仅“有限可信（含自报）”，不宣称掌握。未解且未披露的方向不展开，导致早期薄弱点识别更保守。

L0 分布包含尚未请求 AI 的记录，不能等同于实际查看过一条 L0 回复。训练题目难度/Tags 来自当前可信缓存，历史未保存训练时元数据版本；后续官方元数据变更可能影响画像。官方 Tags 关联不证明卡点原因；词汇匹配会漏检、误匹配，不证明 AI 结论正确。每题最新复盘可能不包含以前的风险，不累加多次追问制造重复证据。更早训练和 200 题以外复盘未纳入画像；反馈窗口也有限。600 候选不是全库最优，首标签分层受官方标签顺序影响。没有反馈只维持确定性排序，不随机编造多样性。

元数据/历史不足安全降级：无匹配不出题，缺 Rating 不猜测，缺 Tags 仅难度/记录参与均衡推荐，缓存失败复用旧缓存并告知过期；无可信缓存返回安全 503，学习自评/画像仍可独立读取。配置完整不表示已连接。

下一阶段建议：采集官方提交证据并明确来源/源码未核实，不提供提交浏览器；人工评价推荐适配、解释准确性和复盘词汇提取，按证据调整权重，另验收托管双用户/多连接。不增加 ML、多 Agent 或基础设施。
